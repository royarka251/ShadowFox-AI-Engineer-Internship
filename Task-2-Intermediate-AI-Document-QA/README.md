
# ShadowFox AI Engineer Internship

## Task 2: Intermediate AI Document Q&A Assistant

A document-based question-answering application that retrieves relevant information from uploaded PDF and TXT files.

### Key Features
- PDF and TXT document upload
- Text extraction and chunking
- Text embeddings and vector similarity search
- Context-grounded question answering
- Retrieved source context display
- Gradio web interface

### Technologies
- Python
- Google Colab
- Gradio
- Sentence Transformers
- FAISS (if used in the notebook)

### Testing
Tested using a synthetic practice document covering embeddings, chunking, and document-grounded question answering.

The practice document is synthetic and is not an official ShadowFox document.
