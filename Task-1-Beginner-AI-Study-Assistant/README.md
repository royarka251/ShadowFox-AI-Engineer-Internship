
# AI Study Assistant

## ShadowFox AI Engineer Internship — Beginner Task

AI Study Assistant is a simple AI-powered study utility built with Python, Gradio, and the Gemini API.

## Features
- Summarize study notes
- Generate multiple-choice quizzes
- Explain difficult topics in simple language
- Validate empty input
- Display errors when an AI request fails

## Technologies
- Python
- Google Gemini API
- Gradio
- Google Colab

## How to Run
1. Install the packages listed in requirements.txt.
2. Set your Gemini API key securely using the GEMINI_API_KEY environment variable.
3. Run the application with Python.
4. Open the local Gradio URL shown in the terminal.
